> Un mot ou un sigle inconnu ? Passe la souris dessus, ou ouvre le [glossaire](../../ressources/glossaire.md).

## Méthode

Analyse du besoin → plan d'adressage → schéma → déploiement par couches → tests → documentation.

| Phase | À produire |
|---|---|
| 1. Adressage | Plan VLSM, tableau VLAN |
| 2. Réseau | Configuration des switchs et du routeur, tests inter-VLAN |
| 3. Windows | Domaine, OU, groupes, GPO |
| 4. Services | DHCP avec relais, DNS, partages, accès sécurisé |

**Documenter au fur et à mesure** : la fiche de documentation se remplit pendant le TP, pas après.
