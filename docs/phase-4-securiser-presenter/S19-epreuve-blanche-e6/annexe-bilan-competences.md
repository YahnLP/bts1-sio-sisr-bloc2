# Annexe – Bilan de positionnement sur le bloc 2

*BTS SIO SISR 1re année – Bloc 2 – S19*

Ce bilan sert à **décider de ce que tu travailleras en deuxième année**. Remplis-le seul, honnêtement : un niveau sous-estimé se corrige, un niveau surestimé est une fausse sécurité.

## Niveaux

Le vocabulaire est celui des grilles nationales d'évaluation.

| Niveau | Ce que ça signifie |
|---|---|
| **Non maîtrisé** | Je ne sais pas encore le faire |
| **Maîtrise partielle** | Je sais le faire avec de l'aide |
| **Bonne maîtrise** | Je sais le faire seul, correctement |
| **Excellente maîtrise** | Je le fais seul, correctement, je l'explique et je peux l'adapter à un autre contexte |
| **Non évalué** | Je n'ai pas travaillé cette compétence |
