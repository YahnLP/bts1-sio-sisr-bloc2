## Objectifs

À la fin de la séance, l'étudiant est capable de :

1. **Corriger** les dysfonctionnements résiduels d'une infrastructure déployée ;
2. **Dérouler** un plan de test et **conclure** sur la conformité au cahier des charges ;
3. **Rédiger** un DAT : contexte, architecture, choix justifiés, procédures ;
4. **Produire** des schémas exploitables par un tiers ;
5. **Rédiger** une fiche descriptive de réalisation (modèle E6).
