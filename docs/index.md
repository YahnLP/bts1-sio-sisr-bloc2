Un survol d'un sigle (VLAN, DHCP, GPO…) affiche une infobulle ; le [glossaire](ressources/glossaire.md) les réunit tous. Les encadrés `Remarque`, `Astuce` et `Attention` signalent les points à ne pas manquer.
