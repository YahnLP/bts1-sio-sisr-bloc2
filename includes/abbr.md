*[APIPA]: Adresse d'auto-configuration : Adresse en 169.254.x.x qu'une machine Windows s'attribue seule faute de serveur DHCP : signe d'un problème.
*[IPv6]: Adresse de nouvelle génération : Adresses sur 128 bits écrites en hexadécimal, conçues pour remplacer l'IPv4.
*[IP]: Adresse IP : Numéro qui identifie une machine sur un réseau (exemple : 192.168.1.20).
*[MAC]: Adresse MAC : Numéro d'identification de la carte réseau (6 octets), utilisé sur le réseau local.
*[PSU]: Alimentation redondante : Bloc d'alimentation d'un serveur ; un serveur en possède souvent deux pour résister à la panne de l'un.
*[AD]: Annuaire de Microsoft : Annuaire utilisé dans les entreprises Windows.
*[STP]: Arbre recouvrant : Protocole qui bloque certains liens redondants pour éviter les boucles entre commutateurs.
*[DHCP]: Attribution automatique d'adresses : Service qui donne automatiquement une adresse IP aux machines qui se connectent.
*[RJ45]: Câble à paires torsadées : Connecteur à 8 broches des câbles Ethernet en cuivre.
*[SSH]: Connexion sécurisée à distance : Prendre le contrôle d'un terminal sur une autre machine, par une connexion chiffrée.
*[UAC]: Contrôle de compte d'utilisateur : Fenêtre de Windows qui demande une confirmation avant une action d'administrateur.
*[DC]: Contrôleur de domaine : Serveur qui héberge l'annuaire Active Directory et authentifie les utilisateurs.
*[VLSM]: Découpage en sous-réseaux de tailles variables : Technique qui découpe un réseau en sous-réseaux de tailles différentes, adaptées aux besoins.
*[HDD]: Disque dur : Stockage à plateaux tournants : grand, peu cher, assez lent.
*[SSD]: Disque SSD : Stockage sans pièce mobile (mémoire flash) : plus rapide et plus résistant aux chocs qu'un disque dur.
*[DAT]: Dossier d'architecture technique : Document qui décrit une infrastructure : besoins, schémas, choix, configuration, tests, exploitation.
*[RTO]: Durée maximale d'interruption admise : Le temps maximum acceptable pour remettre le service en marche après une panne.
*[RAID]: Grappe de disques : Plusieurs disques utilisés ensemble pour gagner en vitesse et/ou résister à la panne d'un disque. Ce n'est pas une sauvegarde.
*[HA]: Haute disponibilité : Conception qui permet à un service de continuer malgré la panne d'un élément.
*[IOS]: Interface en ligne de commande de Cisco : Système des équipements Cisco, administré en ligne de commande.
*[GUI]: Interface graphique : On commande avec la souris, des fenêtres et des icônes.
*[CLI]: Ligne de commande : On commande en tapant du texte dans un terminal.
*[ACL]: Liste de contrôle d'accès : Liste des utilisateurs et groupes autorisés (ou refusés) sur un dossier ou un fichier, avec leurs droits.
*[VM]: Machine virtuelle : Un ordinateur simulé par un logiciel, qui tourne dans une fenêtre de l'ordinateur réel.
*[RAM]: Mémoire vive : Mémoire rapide où l'ordinateur place ce qu'il utilise en ce moment ; elle se vide quand on éteint.
*[BIOS]: Micrologiciel de démarrage : Programme inscrit sur la carte mère qui démarre la machine avant le système ; ancienne génération.
*[UEFI]: Micrologiciel de démarrage moderne : Remplaçant moderne du BIOS : démarrage plus rapide, disques de grande taille, démarrage sécurisé.
*[OSI]: Modèle OSI : Découpage théorique de la communication réseau en 7 couches, utilisé pour situer un problème.
*[CIDR]: Notation de masque en nombre de bits : Écriture /24 qui indique combien de bits du début de l'adresse désignent le réseau.
*[SMB]: Partage de fichiers de Windows : Protocole des partages de fichiers Windows (dossiers partagés, imprimantes).
*[RPO]: Perte de données maximale admise : La quantité de données (exprimée en temps) que l'on accepte de perdre.
*[LAMP]: Pile de services web : Ensemble Linux, Apache, MariaDB et PHP qui permet d'héberger un site web dynamique.
*[CPU]: Processeur : Le composant qui exécute les instructions des programmes.
*[LDAP]: Protocole d'annuaire : Langage pour interroger un annuaire.
*[TCP/IP]: Protocole de communication réseau : L'ensemble de règles de communication utilisé par Internet.
*[ICMP]: Protocole de messages de contrôle : Protocole des messages de diagnostic et d'erreur ; c'est lui qui transporte le `ping`.
*[SNMP]: Protocole de supervision réseau : Permet d'interroger à distance un équipement réseau (imprimante, commutateur) sur son état.
*[VLAN]: Réseau local virtuel : Découpage logique d'un commutateur en plusieurs réseaux séparés.
*[VPN]: Réseau privé virtuel : Tunnel chiffré qui relie deux réseaux ou un poste distant à un réseau en passant par Internet.
*[ARP]: Résolution d'adresses : Protocole qui retrouve l'adresse MAC correspondant à une adresse IP du réseau local.
*[AD DS]: Services de domaine Active Directory : Rôle Windows Server qui fournit l'annuaire et l'authentification du domaine.
*[GPO]: Stratégie de groupe : Règles appliquées automatiquement aux comptes et aux postes Windows d'un domaine.
*[IDS]: Système de détection d'intrusion : Outil qui surveille le réseau ou une machine et signale les comportements suspects.
*[NTFS]: Système de fichiers de Windows : Système de fichiers de Windows, qui gère des droits d'accès précis sur chaque dossier et fichier.
*[DFS]: Système de fichiers distribué : Présente plusieurs partages répartis sur différents serveurs sous une arborescence unique.
*[DNS]: Système de noms de domaine : Annuaire d'Internet : il traduit un nom (www.exemple.fr) en adresse IP.
*[NAT]: Traduction d'adresses : Le routeur fait passer les machines du réseau privé sur Internet avec sa propre adresse.
*[FTP]: Transfert de fichiers : Protocole de transfert de fichiers, non chiffré ; à remplacer par SFTP.
*[SFTP]: Transfert de fichiers sécurisé : Transfert de fichiers à l'intérieur d'une connexion SSH chiffrée.
*[OU]: Unité d'organisation : Dossier de l'annuaire qui regroupe des comptes et des ordinateurs pour leur appliquer des règles.
*[DMZ]: Zone démilitarisée : Réseau intermédiaire qui héberge les serveurs accessibles depuis Internet, isolé du réseau interne.
